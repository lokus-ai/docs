## What's inside

- **Editor** — markdown-first, with wiki links, embeds, callouts, math, and live preview
- **Organize** — folders, tags, tasks, kanban boards, databases (Bases), daily notes
- **Think** — graph view, canvases, templates, full-text search
- **Extend** — plugins with commands, panels, status-bar widgets, and overlays
- **Everywhere** — macOS, Windows, Linux, with optional encrypted sync
